# iris-ann-classification
Deep Learning ANN model for Iris flower classification using TensorFlow/Keras. Includes preprocessing, training, evaluation, and visualization of accuracy/loss curves.
# Iris ANN Classification 🌸

## 📌 Overview
This project implements an Artificial Neural Network (ANN) using TensorFlow/Keras to classify Iris flowers into three species (Setosa, Versicolor, Virginica).  
It demonstrates preprocessing, model training, evaluation, and visualization of accuracy/loss curves.

## ⚙️ Requirements
- Python 3.8+
- TensorFlow / Keras
- pandas, numpy
- matplotlib, seaborn

Install dependencies:
```bash
pip install tensorflow pandas numpy matplotlib seaborn
